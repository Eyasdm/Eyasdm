## Projects

### 🏆 IndabaX Sudan ML Hackathon — 4th / 132 teams
Agricultural dry spell prediction model for Sudan. Binary classification on 17 years of daily climate data — soil moisture, vapor pressure deficit, sea surface temperatures, atmospheric pressure. HistGradientBoosting with a 3-model rank ensemble and recency-weighted predictions for temporal drift. The direct inspiration for AgroSense.

→ [`indabax-dryspell-prediction`](https://github.com/Eyasdm/indabax-dryspell-prediction)
